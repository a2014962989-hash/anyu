# Reviewed object/action relation formulation screen

Root decision: CLOSED_CURRENT_OBJECT_ACTION_RELATION_FORMULATION_NO_DISTINCT_VALIDATION_READY_CONTRIBUTION. This closes the current formulation under current data and validation conditions. It does not establish that every future relation target is impossible, or that a limited search proves novelty absent.

Six official primary papers were reviewed in three search batches. Ordinary ordered span-pair classification has direct precedents. Renaming concatenation, bilinear scoring, rationale classification or attention alignment does not by itself supply a distinct method contribution.

Root required three corrections and accepted the bounded derivations: a verified selected positive pair can carry relation information, while leaving unselected matrix cells unspecified; exhaustive annotation is not universally required when a defined finite population has reliable labels and known strictly positive sampling inclusion probabilities; linear loss and confusion totals can then be estimated by design-unbiased weighting, whereas an F1 ratio is generally not finite-sample unbiased. The matrix completion argument concerns information in recorded supervision without additional semantic constraints, not two semantic truths for an identical fixed text.

Wang et al.'s CSPO uses complementary masked pair/context views from the same instance. Cross-instance negatives are instance-matching objectives, not automatic semantic relation negatives. Cross-post span exchange therefore supplies no default negative relation label.

The correction stage took 1,175.845 seconds against a 900-second cap; the 275.845-second timing deviation remains recorded. Root also repaired a scope transfer in the final documentation: prior human confirmation of an older batch does not establish the workflow of a later independent return. The earlier data-qualification decision remains unchanged. No new human gold or independent confirmation has been accepted; no implementation, training, annotation or confirmation access is authorized. The overall research gates remain incomplete.
